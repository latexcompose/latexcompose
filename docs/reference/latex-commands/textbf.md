# `\textbf`

Formats a text in bold font.

## LaTeX syntax
```latex
\textbf{<text>}
```

For further information see
[https://latexref.xyz/Font-styles.html](https://latexref.xyz/Font-styles.html){:target="_blank" rel="noopener noreferrer"}

## Python example
```python
Textbf("latexcompose is awesome!")
```

## Generated LaTeX code

```latex
\textbf{latexcompose is awesome!}
```
