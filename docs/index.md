# Welcome

**latexcompose** is a Python library to generate LaTeX code and to build
extensions based on this library. The main motivation for creating this
library was to build domain specific languages for creating diagrams
based on the LaTeX library **TikZ**.

## Is latexcompose right for you?

**latexcompose** is designed for developers who want to combine
the flexibility of Python with the power and quality of LaTeX.
It is particularly useful if you:

:lucide-circle-check:{ style="color: green" }
You understand the basics of LaTeX

:lucide-circle-check:{ style="color: green" }
Are familiar with object-oriented programming, especially inheritance

:lucide-circle-check:{ style="color: green" }
You are looking for a extendable and highly customizable library

:lucide-circle-check:{ style="color: green" }
Want to integrate high-quality document generation into your applications

:lucide-circle-check:{ style="color: green" }
Enjoy combining Python with LaTeX

## When latexcompose might not be the right choice

Of course, latexcompose is not for everyone. You might want
to consider another solution if you:

:lucide-circle-x:{ style="color: red" }
Have no experience with LaTeX

:lucide-circle-x:{ style="color: red" }
Expect less code than writing LaTeX directly

:lucide-circle-x:{ style="color: red" }
Prefer to avoid object-oriented programming

:lucide-circle-x:{ style="color: red" }
Just need a quick solution

**In short:** If you know your way around LaTeX, enjoy
object-oriented Python, and want to build sophisticated
document-generation solutions, latexcompose might be exactly
what you are looking for!
